# CodeAlpha C Programming Internship Tasks

This folder contains four C programming tasks from the CodeAlpha internship task sheet.

## Tasks
1. Basic Calculator Program — switch case
2. Matrix Operations — addition, multiplication and transpose using functions and 2D arrays
3. Student Management System — structures and file handling
4. Banking System — mini project using functions, structures and file handling

The internship instructions require completing any 2 or 3 of the 4 tasks. All four are included here so you can choose the required submissions.

## Compile
Using GCC:

gcc Task1_Calculator.c -o calculator
gcc Task2_Matrix_Operations.c -o matrix
gcc Task3_Student_Management.c -o student
gcc Task4_Banking_System.c -o banking

## Notes
- Task 3 creates `students.dat` when records are added.
- Task 4 creates `accounts.dat` when accounts are created.
- The `.dat` files are generated at runtime and are not required for the source-code submission.
- Before submitting, test each program and replace the GitHub repository name/links in your LinkedIn post as required by CodeAlpha.
